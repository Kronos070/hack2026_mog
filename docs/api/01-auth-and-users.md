# 01. Аутентификация и управление пользователями

Этот модуль отвечает за учет игроков, безопасный вход, хранение игрового баланса бонусов и личных настроек профиля.

---

## 🎯 Зачем нужен этот модуль

Каждому игроку в «Воздушном Шаре» необходим аккаунт, к которому привязаны:
1. **Бонусный баланс (`bonusBalance`)** — внутренняя валюта ставок в бонусах Столото. При регистрации каждому новому игроку автоматически начисляется подарок: **1 000 бонусов**.
2. **Турнирные очки (`points`)** — очки суточного соревнования, которые начисляются за успешные кэшауты, пройденные уровни полета и активацию бустеров.
3. **Мета-прогресс** — собранные кусочки пазла, разблокированные достижения, текущий ранг и статистика последних 30 раундов (радар).

---

## 1. Регистрация нового игрока

### `POST /api/auth/register`
Создает учетную запись нового пользователя и сразу возвращает авторизационный токен (повторный логин после регистрации делать не нужно).

- **Заголовки:** `Content-Type: application/json`
- **Авторизация:** Не требуется (публичный эндпоинт)

#### Тело запроса (JSON)
```json
{
  "username": "sky_pilot_99",
  "email": "pilot99@stoloto.ru",
  "password": "secretPassword123",
  "firstName": "Иван",
  "lastName": "Петров",
  "avatarUrl": "https://api.dicebear.com/7.x/bottts/svg?seed=sky_pilot_99"
}
```

#### Описание полей запроса:
| Поле | Тип | Обязательное | Описание и валидация |
|---|---|:---:|---|
| `username` | string | **Да** | Уникальный логин игрока (от 3 до 64 символов, без пробелов). |
| `email` | string | **Да** | Валидный адрес электронной почты (до 128 символов). |
| `password` | string | **Да** | Пароль (от 6 до 100 символов). На сервере хэшируется через BCrypt. |
| `firstName` | string | Нет | Имя игрока для отображения в профиле (до 64 символов). |
| `lastName` | string | Нет | Фамилия игрока (до 64 символов). |
| `avatarUrl` | string | Нет | Ссылка на аватар пользователя (до 512 символов). |

#### Успешный ответ `200 OK`
```json
{
  "token": "eyJhbGciOiJSUzI1NiIsInR5cCI6IkpXVCJ9...",
  "tokenType": "Bearer",
  "expiresIn": 86400,
  "user": {
    "id": 42,
    "username": "sky_pilot_99",
    "email": "pilot99@stoloto.ru",
    "bonusBalance": 1000,
    "points": 0,
    "firstName": "Иван",
    "lastName": "Петров",
    "avatarUrl": "https://api.dicebear.com/7.x/bottts/svg?seed=sky_pilot_99",
    "role": "USER",
    "createdAt": "2026-09-12T10:00:00Z",
    "updatedAt": "2026-09-12T10:00:00Z"
  }
}
```

> **Совет для фронтенда:**  
> Сохраните `token` в `localStorage` или cookie и добавьте его в дефолтный заголовок вашего HTTP-клиента (например, Axios instance):  
> `headers.Authorization = 'Bearer ' + token;`

#### Возможные ошибки:
- `400 Bad Request` — не заполнено обязательное поле или пароль короче 6 символов.
- `409 Conflict` — пользователь с таким `username` или `email` уже зарегистрирован.

## 2. Вход в систему (Авторизация)

### `POST /api/auth/login`
Авторизация по логину (`username` или `email`) и паролю.

- **Заголовки:** `Content-Type: application/json`
- **Авторизация:** Не требуется

#### Тело запроса (JSON)
```json
{
  "login": "sky_pilot_99",
  "password": "secretPassword123"
}
```
*Примечание: в поле `login` можно передавать как логин (username), так и email.*

#### Успешный ответ `200 OK`
Возвращает такой же объект `AuthResponse`, как и при регистрации (токен на 24 часа + данные профиля с актуальным балансом и очками).

#### Быстрый доступ для тестов:
- **Предустановленный администратор:**
  - **Логин:** `admin` (или `admin@stoloto.ru`)
  - **Пароль:** `admin123`
  - **Особенности:** Роль `ADMIN`, начальный баланс 50 000 бонусов, 5 000 турнирных очков.
- **Предустановленный тестовый пользователь:**
  - **Логин:** `test_user` (или `test_user@stoloto.ru`)
  - **Пароль:** `test1234`
  - **Имя:** Тестовый Пользователь
  - **Особенности:** Роль `USER`, начальный баланс 10 000 бонусов, средний ранг `aeronaut` («Воздухоплаватель»), 0 достижений.

#### Возможные ошибки:
- `401 Unauthorized` — неверный логин или пароль (`"Неверные учетные данные"`).

## 3. Быстрая проверка текущего пользователя

### `GET /api/auth/me`
Простой запрос для проверки валидности токена при обновлении страницы приложения.

- **Авторизация:** `Authorization: Bearer <token>`
- **Ответ `200 OK`:** Объект `UserProfileResponse` (id, username, email, bonusBalance, points, role, аватар).
- **Ошибка `401 Unauthorized`:** Токен просрочен или не передан — перенаправьте пользователя на страницу входа.

## 5. Обновление профиля и смена пароля

### `PUT /api/users/me` — Изменение личных данных
Позволяет пользователю обновить свой никнейм, email, имя или аватарку.
- **Авторизация:** `Authorization: Bearer <token>`
- **Тело запроса:** Все поля опциональны. Передавайте только те, которые изменились:
```json
{
  "username": "sky_king",
  "firstName": "Алексей",
  "avatarUrl": "https://example.com/new-avatar.png"
}
```
- **Ответ `200 OK`:** Обновленный объект `UserProfileResponse`.

### `PUT /api/users/me/password` — Смена пароля
- **Авторизация:** `Authorization: Bearer <token>`
- **Тело запроса:**
```json
{
  "oldPassword": "secretPassword123",
  "newPassword": "newSecretPassword456"
}
```
- **Ответ `200 OK`:** `{"message": "Пароль успешно изменен"}`.
- **Ошибки:** `400 Bad Request` при несовпадении старого пароля или если новый пароль короче 6 знаков.

### `DELETE /api/users/me` — Удаление аккаунта
- **Авторизация:** `Authorization: Bearer <token>`
- **Ответ `204 No Content`** (тело ответа пустое). Клиенту следует очистить сессию и перенаправить на страницу логина.

## 6. Публичный просмотр профилей других игроков

### `GET /api/users/{id}`
Позволяет открыть модальное окно или страницу профиля любого соперника из турнирной таблицы или истории ставок.
- **Авторизация:** Не требуется (публичный эндпоинт).
- **Ответ `200 OK`:** Объект `ProfileDto` выбранного пользователя.
- **Ошибка `404 Not Found`:** Если игрока с таким ID не существует.

### `GET /api/users` — Список всех игроков
Используется в админке или для общего каталога игроков.
- **Параметры:** `?page=0&size=20` (по умолчанию страница 0, размер 20).
- **Ответ `200 OK`:**
```json
{
  "items": [ /* массив UserProfileResponse */ ],
  "page": 0,
  "size": 20,
  "totalElements": 85,
  "totalPages": 5
}
```

## 7. 🎁 Тестовое пополнение баланса бонусов (Top-Up)

Во время хакатона, демонстраций и ручного тестирования баланс игрока может закончиться. Специально для этого на бэкенде предусмотрены быстрые эндпоинты пополнения без проверок и банковских шлюзов!

### 7.1. Пополнение собственного баланса
`POST /api/users/me/top-up` или `POST /api/game/top-up` (алиас)
- **Авторизация:** `Authorization: Bearer <token>`
- **Тело запроса:**
```json
{
  "amount": 5000
}
```
*(Если отправить пустое тело `{}` — сервер автоматически начислит `1000` бонусов).*
- **Ответ `200 OK` (`TopUpBalanceResponse`):**
```json
{
  "userId": 42,
  "username": "sky_pilot_99",
  "addedAmount": 5000,
  "newBalance": 6450
}
```

### 7.2. Пополнение баланса любого игрока по ID
`POST /api/users/{id}/top-up`
- **Авторизация:** Не требуется (удобно дергать из консоли браузера, curl или Postman/Swagger).
- **Параметр URL:** `id` пользователя.
- **Тело запроса:** `{"amount": 10000}` (или `{}`).

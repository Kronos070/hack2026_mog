## 🏛 4 принципа математической честности MOG

1. **Строгий серверный авторитет (Server-Authoritative):**  
   Точка краха, уровень бустера и выигрыш определяются исключительно на сервере. Клиентский браузер является лишь графическим визуализатором.
2. **Криптографическая доказуемость (Provably Fair):**  
   До подтверждения ставки игрок получает SHA-256 хэш исхода. После окончания раунда сервер раскрывает `serverSeed`, позволяя игроку проверить исход по формуле до единого знака.
3. **Защита банка оператора и анти-Мартингейл:**  
   Динамическая модель House Edge автоматически повышает преимущество при серии выигрышей и мгновенно сбрасывает накопленные бонусы к $HE_{base}$ при попытке удвоения ставки.
4. **Удержание через гарантированные награды:**  
   Даже при проигрыше игрок получает турнирные очки за пройденные высотные уровни и накапливает прогресс в Pity Timer для получения коллекционных фрагментов пазла.

## 🚀 Быстрый запуск инструментов верификации

### 1. Симуляция Monte Carlo (1 000 000 раундов)
Проверка теоретического закона распределения и подтверждение $RTP = 96.00\%$:
```bash
python3 docs/math/scripts/simulate_rtp.py 1000000
```

### 2. Верификация честности любого раунда
Проверка совпадения серверного хэша и множителя краша:
```bash
npx ts-node docs/math/scripts/verify_crash.ts
```

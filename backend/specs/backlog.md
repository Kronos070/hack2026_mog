# Открытый бэклог хакатона (Backlog)

Статус: reference / current · сверено: 2026-09-12

Список задач, которые предстоит реализовать на хакатоне. Когда задача закрыта — строка удаляется отсюда и переносится в [backlog-resolved.md](backlog-resolved.md) с кратким описанием решения.

---

## Высокий приоритет (Игровой цикл и админка)
- [ ] **CFG-1**: Админский REST API параметров игры (`GET /api/admin/config`, `PUT /api/admin/config`) с горячим hot-reload кэшем в памяти `GameConfigService`.
- [ ] **CFG-2**: Тюнинг темпа роста коэффициента (повышение `multiplierGrowthRate` до 0.25 для динамичного раунда 3-8 сек) и динамическое чтение из конфига.

## Средний приоритет (Турнир и таблица лидеров)
- [ ] **TOUR-1**: Автоматическое начисление турнирных очков за раунды в `tournament_entries`.
- [ ] **TOUR-2**: REST эндпоинты турнира и живого лидерборда (`GET /api/tournament`, `GET /api/tournament/leaderboard`).

## Геймификация и удержание (Мета-игра Столото)
- [ ] **META-1**: Коллекция наград / пазлов (ТЗ §1.5) — таблица `user_puzzle_pieces`, выдача фрагментов за раунды, возврат объекта `reward` в результатах.
- [ ] **META-2**: Расчет динамических рангов игрока по чистой прибыли (`profit = totalPayout - totalWagered`) — 6 рангов Столото.
- [ ] **META-3**: Система достижений (10 ачивок) — таблица `user_achievements`, проверка условий и возврат `unlockedAchievements`.
- [ ] **META-4**: Расширенная статистика профиля (`GET /api/users/me` — `roundsPlayed`, `roundsWon`, `bestMultiplier`, `totalWagered`, `totalPayout`, пазлы, ачивки, ранг).
